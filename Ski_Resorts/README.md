# Ski Resorts Content Pack for ForeFlight

**Download:** [Ski_Resorts_Pack.zip](https://github.com/ingramleedy/ForeFlightContentPacks/blob/main/Ski_Resorts/Ski_Resorts_Pack.zip?raw=true)

A ForeFlight content pack mapping US ski resorts sourced from Wikipedia's *Comparison of North American ski resorts*. Placemarks are color-coded by vertical drop so you can instantly see the biggest mountains along any route.

**Current version:** `2026.05.18`
**Resorts mapped:** 384 US ski resorts (28 big mountain, 90 major, 134 regional, 132 local)
**Pack size:** ~29 KB zipped

## Content Overview

The pack ships a single map layer covering all US ski resorts.

### Icon color coding by vertical drop

Icons scale in size with tier so the biggest mountains are visually prominent when zoomed out:

| Icon | Tier | Vertical Drop |
|---|---|---|
| ⭐ Gold star (large) | Big Mountain | 3,000+ ft — major destination resorts |
| 🟠 Orange circle | Major Resort | 1,500–2,999 ft |
| 🟡 Yellow circle | Regional Resort | 500–1,499 ft |
| 🔵 Blue circle (small) | Local Hill | < 500 ft |

### What you get when you tap a pin

- **Resort name** and state
- **Tier** (Big Mountain / Major Resort / Regional Resort / Local Hill)
- **Vertical Drop** (ft)
- **Summit Elevation** (ft MSL) — useful for density-altitude awareness when planning mountain approaches
- **Base Elevation** (ft MSL)
- **Trails**, **Lifts**, **Skiable Acreage**
- **Average Annual Snowfall** (inches)
- **Nearest airports** within 75 miles (ICAO + distance)

### Why this is useful for pilots

Flying to pick up skiing friends or planning a fly-ski trip? The gold-star layer shows all big-mountain destination resorts at a glance. Tap any pin while route planning to see the nearest airports with distances — combine with ForeFlight's weather overlay to pick the best valley airport for your mountain destination.

The summit elevation field matters: many Western ski resort summits are 11,000–14,000 ft MSL. A gold-star resort means a 10,000+ ft base elevation in many cases — factor that into your density altitude and turbulence planning.

## Build pipeline

```
scripts/
├── fetch_resorts.py    Wikipedia → geocode via Nominatim → data/ski_resorts.json
├── build_kml.py        data/ski_resorts.json → pack/layers/Ski_Resorts.kml
├── validate_pack.py    pre-zip gate
└── package.py          manifest bump + validate + zip

data/
└── ski_resorts.json    generated by fetch_resorts.py (git-ignored; regenerate to refresh)
```

To rebuild from scratch:

```bash
cd Ski_Resorts
python scripts/fetch_resorts.py   # ~8 min for geocoding
python scripts/build_kml.py
python scripts/package.py
```

### Source

Data sourced from Wikipedia: *[Comparison of North American ski resorts](https://en.wikipedia.org/wiki/Comparison_of_North_American_ski_resorts)*. Coordinates via Nominatim / OpenStreetMap. This pack is provided for personal use.

## Importing the Content Pack into ForeFlight

Detailed instructions: [ForeFlight Content Packs Support](https://www.foreflight.com/support/content-packs/).

1. Download the ZIP using the link at the top of this README.
2. On iOS/iPadOS: open in Safari → Downloads → Share → **ForeFlight**.
3. ForeFlight will unpack and install the pack.
4. Restart ForeFlight if layers don't appear immediately.
5. In ForeFlight: **More → Content Packs**, toggle the pack on. On the **Maps** view, enable the Ski Resorts layer from the layer selector.

*Note: Content packs require manual re-download for updates, unless using the Cloud Storage sync described in the [root README](../README.md#addendum-syncing-content-packs-via-cloud-storage-eg-onedrive).*
